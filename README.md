# SAHROUD-METREH

نرم‌افزار ترسیم، متره و برآورد ساختمان؛ خروجی گزارش، CSV و DXF.

## اجرای برنامه
- فایل اصلی برنامه: `index.html` در ریشه مخزن.
- برای انتشار: در GitHub وارد **Settings → Pages** شوید؛ در بخش **Build and deployment** گزینه **Deploy from a branch**، شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
- پس از فعال شدن، نشانی سایت معمولاً `https://sahroud.github.io/SAHROUD-METREH/` خواهد بود.

## قیمت‌ها: تمایز الزامی منابع
این برنامه دو نوع داده را نباید با هم اشتباه بگیرد:
1. **مبنای رسمی برآورد**: فهرست‌بهای پایه سازمان برنامه و بودجه (سالانه) و شاخص‌های تعدیل (دوره‌ای). این‌ها نرخ روز تحویل مصالح در شهر پروژه نیستند.
2. **قیمت روز بازار**: برای برخی اقلام مانند فولاد و سیمان می‌توان از معاملات بورس کالای ایران استفاده کرد؛ برای مصالح محلی فاقد معامله بورسی، باید استعلام تاریخ‌دار تأمین‌کننده همان شهر ثبت شود. هیچ مرجع رسمی واحدی قیمت روزانه همه مصالح را برای همه شهرها منتشر نمی‌کند.

مراجع رسمی:
- سامانه امور نظام فنی و اجرایی سازمان برنامه و بودجه: https://sama.mporg.ir/
- سازمان برنامه و بودجه: https://www.mporg.ir/
- مرکز آمار ایران: https://www.amar.org.ir/
- نظام فنی و اجرایی کشور: http://nezamfanni.ir
- بورس کالای ایران: https://www.ime.co.ir/

## اتصال سرویس قیمت
فایل `sahroud-metreh-price-worker.js` یک **درگاه امن** Cloudflare Worker است، نه منبع قیمت و نه scraper. برای فعال شدن دریافت خودکار:
- Worker را در Cloudflare مستقر کنید.
- متغیر `ALLOWED_ORIGIN` را دقیقاً برابر origin سایت Pages قرار دهید؛ نمونه: `https://sahroud.github.io`.
- `PRICE_PROVIDER_URL` را به یک API واقعی و مجاز وصل کنید که قیمت‌ها را از معاملات بورس کالا و/یا استعلام‌های معتبر تأمین‌کنندگان دریافت و به JSON سازگار تبدیل کند.
- در صورت نیاز، کلید دسترسی را فقط به‌صورت Secret با نام `PRICE_PROVIDER_KEY` در Cloudflare ثبت کنید؛ هرگز در HTML یا GitHub قرار ندهید.
- نشانی Worker را در برنامه از دکمه «تنظیم نشانی سرویس قیمت» وارد کنید.

پاسخ API باید شهر و واحد پول درخواستی را عیناً برگرداند. هر قلم باید `name`، `unit`، `material` و/یا `labor`، `source` و `updatedAt` داشته باشد. نرخ بازار قدیمی‌تر از ۴۸ ساعت، بدون منبع، با واحد متفاوت یا شهر نامنطبق در برنامه پذیرفته نمی‌شود. نرخ بورس کالا باید به‌عنوان «قیمت معامله بورس / تحویل طبق اطلاعیه» شناخته شود و بدون افزودن هزینه حمل و مالیات، قیمت تحویل پروژه معرفی نشود.

**وضعیت فعلی:** برنامه و درگاه Worker در مخزن قرار گرفته‌اند، اما API تأمین‌کننده هنوز تعیین و پیکربندی نشده است؛ بنابراین دریافت خودکار قیمت روز هنوز فعال نیست و نرخ‌های اولیه صرفاً نمونه‌اند. هیچ مبلغ نمونه‌ای را نرخ رسمی یا روز تلقی نکنید.
